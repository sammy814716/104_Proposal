# 104 職涯探索首頁改版 Prototype

104 職涯探索首頁個人化改版的手機版高保真互動 prototype，面試提案作業。

🔗 **Live Demo**：https://sammy814716.github.io/104_Proposal/

## 專案說明

重新設計 104 職涯探索首頁的資訊架構與個人化邏輯：使用者一進首頁即可選擇自己目前的職涯階段
（探索方向中／積極求職中／考慮轉職中／穩定工作中，單選），首頁內容、工具與資源會立即依所選
狀態調整，不需要先完成測驗或填表才能使用。

## 功能重點

- **職涯階段選擇**：4 張可單選需求卡片，橫向 carousel 呈現，預設選中「積極求職中」
- **個人化工具區塊**：依身份顯示對應工具（性格測驗 / 必備技能落差卡 / 履歷健診 / 模擬面試等）
- **內容中心**：職場力／職場問答／共學教室整合為單一可捲動區塊，支援標籤篩選與自訂排序

## 技術說明

純前端單一 HTML 檔案（內含所有 CSS / JS），無需伺服器，可直接用瀏覽器開啟，或透過上方 Live Demo 連結線上瀏覽。
